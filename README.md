Ycs
-------

A compatible `.Net` implementation of the [Yjs](https://github.com/yjs/yjs) CRDT framework.

With this, you can host CRDTs in your `.Net` application and synchronize them with the existing `Yjs` models running elsewhere.

#### Verified against Yjs [13.6.32](https://github.com/yjs/yjs/releases) (latest stable) and 14.0.0-16 (beta)

Both update formats round-trip in both directions — see [`interop/`](interop/) and
`tests/Ycs.Tests/YjsInteropTests.cs`. Runs on .NET 8 / .NET 10; the package still targets
`netstandard2.0` as well.

Supports [Y.Array, Y.Map, Y.Text](https://github.com/yjs/yjs#shared-types), including nested
types, embeds and text formatting attributes. **Y.Xml\* is still not implemented** — documents
produced by `y-prosemirror`, `y-quill` and similar bindings throw a `NotSupportedException`
naming the missing type.

### Wire formats

| | Yjs | Ycs |
|---|---|---|
| v1 (default, used by `y-protocols` and every provider) | `Y.encodeStateAsUpdate` / `Y.applyUpdate` | `EncodeStateAsUpdateV1` / `ApplyUpdateV1` |
| v2 (denser) | `Y.encodeStateAsUpdateV2` / `Y.applyUpdateV2` | `EncodeStateAsUpdateV2` / `ApplyUpdateV2` |

`SyncProtocol` speaks v1 by default, matching `y-protocols/sync`; pass `v2: true` on both ends
to use the v2 encoding instead. `YDoc` raises `UpdateV1` and `UpdateV2` for the two formats.

### Changes against upstream `main`

* v1 update encoder/decoder — upstream only implemented v2, which no JS provider speaks.
* v2 `writeJSON`/`readJSON` fixed to use the `any` encoding, as Yjs does. The previous JSON-string
  encoding made every formatted text run and every embed unreadable by Yjs.
* `ReadJson` now yields plain CLR values instead of `Newtonsoft.Json.Linq` tokens.
* Retargeted to `netstandard2.0;net8.0;net10.0`, MSTest 3, Newtonsoft.Json 13.
* Yjs interop tests with fixtures generated by the real library; `interop/run.sh` for the live round-trip.
* The 3.1-era `samples/YcsSample` is no longer part of the solution (stale SPA toolchain, and its
  ProseMirror half needs the missing XML types).

Running the checks
-------

```bash
dotnet test tests/Ycs.Tests/Ycs.Tests.csproj   # 172 tests, no Node needed
./interop/run.sh                                # live round-trip against yjs 13 + 14
```
